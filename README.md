# Artist's Notebook

A tiny, elegant web app for privately collecting artists with your favorite person. Add artists, jot personal notes, tag them, link resources, upload images, and drop in artworks while earning playful badges together.

## Getting started

Open the static site locally:

```bash
# From the repo root
python -m http.server 8000
```

Visit http://localhost:8000/ in your browser.

All data is stored in your browser's `localStorage`, so nothing ever leaves your shared device.

## Features

- Lightweight artist form with image URL, birth year, tags, links, notes, and photo uploads
- Artworks that orbit each artist with title, year, and notes
- Shared point counter that rewards adding artists, details, photos, and artworks
- Badges that unlock as you collaborate: Baby Curator → Gallery Intern → Emerging Taste-Maker → Institutional Powerhouse
- Dark, quiet interface designed for two co-curators
